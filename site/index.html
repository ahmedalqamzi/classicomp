What the client does

How it works

  • It keeps its own catalogue

    Projects are rescanned on a rotation, with box art and screenshots pulled automatically. New releases show up without anyone editing a list.

  • It picks the right build

    Your operating system and CPU decide which release is offered — native builds beat anything needing a compatibility layer, and a build that cannot run on your machine is never offered at all.

  • It installs, properly

    Nested archives are unpacked, Flatpaks registered, and the real executable found among the helpers and uninstallers that ship beside it.

  • It handles the dependencies

    Games needing .NET get it provisioned into Classicomp's own directory — no package manager, no root. Windows-only builds run through Wine in a per-game prefix.

  • It updates without eating your saves

    Installed games update in the background. Saves, settings and mods are lifted out before the old build is replaced and restored afterwards — including when an update fails.

The fine print

About the games

Every title in the catalogue is an independent open-source project — a recompilation, decompilation or source port maintained by its own community. Classicomp links to their releases and installs them for you. It does not host, bundle or distribute any copyrighted game data, and it never will. To play, you supply your own original copy of the game.

Classicomp is free and open source. View the source on GitHub.
